Experimental setup

LLM4MOR successfully reformulates 267 models from MIPLIB 2017 (Find models.zip ↗). A model can give rise to multiple solver instances, one for each associated data set, and the same reformulation is reused across those instances. The final comparison includes 575 instances that passed verification.

Gurobi uses the same settings for both formulations. The results compare solve times, the number of instances solved to optimality, and search node counts. The solve-time comparison excludes LLM reformulation time. A shifted geometric mean (SGM) with a shift of 1 summarizes solve times and node counts.

Solver speedup

Gurobi solves 394 instances to optimality after reformulation, up from 362 before. The overall solver speedup is 2.3× across the 398 instances solved to optimality in at least one run.

LLM reformulation time

Across 267 successfully reformulated models, 2–5 minutes is the most common reformulation time. When solving the same model with different data, you can reuse the reformulated model for each instance. Those few minutes are therefore a reasonable one-time cost per model.
